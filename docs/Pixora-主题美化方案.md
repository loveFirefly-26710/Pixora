# Pixora 主题美化方案

这套主题叫「夜航萤火」。它不是把某个角色的立绘贴到界面上，而是取流萤这一形象的气质：夜里的冷绿微光、薄翼、轨道般的环形结构、少量装甲切面的硬线条。品牌标记、背景光、卡片和信息层级都围绕这一组母题重做。

当前实现保留全部既有功能与接口，只改观感、少量布局和广场上传的默认展开方式。

## 1. 主题与默认值

| 主题 | 定位 | 默认条件 |
|---|---|---|
| 夜航（dark） | 主主题。深墨绿底、银白正文、薄荷萤光、微金点缀 | 系统没有明确偏好时使用 |
| 萤昼（light） | 白天可用的浅色版本。珍珠白、浅薄荷、深绿正文 | 系统偏好浅色时使用 |

首屏由 `index.html` 里的内联脚本在样式加载前写入 `html[data-theme]`，避免深色用户先看到一帧白屏。选择顺序：

1. 用户手动切换过，读 `localStorage["pixora-theme"]`；
2. 没有手动选择，读 `prefers-color-scheme`；
3. 两者都拿不到时回到夜航。

手动切换只影响当前浏览器，不会改站点全局设置。`prefers-color-scheme` 变化只在「没有手动选择」时跟随；选过之后以用户的选择为准。

## 2. 视觉令牌

### 颜色

| 用途 | 夜航 | 萤昼 |
|---|---|---|
| 页面底色 | `#040c0e` | `#eef7f1` |
| 面板/卡片 | `rgba(9,25,25,.72)` | `rgba(255,255,255,.8)` |
| 正文 | `#e8f7f1` | `#102c25` |
| 次级文字 | `#93b2a9` | `#55756b` |
| 主色/强调 | `#a3f7dd` → `#4fe0b6` | `#0e8f71` → `#11a985` |
| 微金 | `#efc887` | `#a06e1e` |
| 分割线 | 薄荷 12% 透明 | 深绿 12% 透明 |

状态色（成功、警告、危险）都改成低饱和的柔和色，并且只在徽标、提示条和进度条里出现，不拿大面积填充。

### 字体与形状

- 正文：系统中文字体栈，不加载外部字体；单二进制离线部署时不依赖 Google Fonts。
- 标题：系统宋体/思源宋体栈，用在广场 hero、页面大标题和卡片标题上。
- 数据：哈希、尺寸、时间、浏览量和版本号用等宽字体。
- 圆角：卡片 `16px`，小控件 `10px`，按钮做胶囊形。
- 阴影：暗色下用深阴影托住玻璃面板，亮色下用很轻的绿灰色阴影。

## 3. 页面与组件

### 外壳

- 顶栏：翼标 + 站名、广场/相册/上传三个主入口、搜索框、主题开关、账号菜单、API 文档。
- 桌面上主入口在顶栏，账号与后台仍走头像菜单；登录后非广场页保留左侧栏，用来放用户中心和后台入口。
- 窄屏隐藏顶栏主入口和侧栏，底部标签栏承接广场/相册/上传/我的。图标不再使用彩色 emoji，改成小圆点与文字。
- 背景：深色径向光、星层、极慢的极光和少量萤火粒子。粒子只在没有开启「减少动态效果」时创建。

### 广场

- 首屏加一块 `.plaza-hero`：左侧品牌文案与「投递影像 / 随机漫游」，右侧圆形「随机一帧」——第一页返回后取第一张公开图，点开就在当前列表里预览；没有图时退回翼标。
- 搜索或标签结果页不显示 hero，让结果直接进第一屏。
- 上传面板在广场使用紧凑形态：只保留投放条、可见性和开始按钮；相册、标签、并发收进完整上传页，通过投放条里的链接进入。选完文件后预览和队列照常出现。
- 图片卡片：标题（用户自己写的标题）、标签、时间、浏览量；悬停时轻微上浮、放大图片、边框发光。相册和回收站不显示浏览量。
- 空状态、骨架屏、加载更多都改成低饱和的萤光语言。

### 图片预览

- 预览层固定为暗房观感，不跟随萤昼变白。
- 顶部标题与计数、左右翻页、底部缩略图、右侧信息栏；信息栏里保留尺寸、大小、格式、相册、上传时间、SHA-256、复制直链和下载。
- 手机上信息栏默认收起，底部保留复制/下载/信息三个按钮。

### 上传页

- 完整上传页保留全部能力：目标相册、标签、可见性、并发数、待上传预览、队列明细、重试、导出成功清单。
- 投放区增加同心圆光轨，拖入时整块变亮。
- 表格式队列行沿用原有状态机，只改视觉。

### 相册

- 页面加可见的大标题和说明。
- 左侧相册栏在桌面上是玻璃面板；窄屏压成横向 chips，隐藏滚动条。
- 网格与列表两种视图都保留。卡片勾选框常驻，选中后边框变薄荷绿并抬起。
- 窄屏工具栏换行：视图切换、排序、全选在一行，搜索框独占下一行，避免横向滚动后被截断。

### 登录与账号入口

- 登录、注册、重置密码、补全邮箱统一使用 `.auth-card` 玻璃卡片和翼标标题。
- 登录页保留账密、手机号、扫码三种面板；第三方入口仍由站点配置决定。
- 顶栏主入口在登录、注册等页不点亮「广场」，只保留品牌和账号入口。

### 后台与账号页

- 卡片、表格、表单、开关、标签、弹窗、条款阅读器全部走同一套令牌，后台页不用逐页写颜色。
- 后台信息密度保持原样，不为了视觉牺牲可读性；表格在窄屏继续转成卡片列表。
- 存储驱动色点保留各自颜色，用作后端身份识别。

## 4. 动效

- 背景：极光缓慢漂移、星层呼吸、少量萤火漂移与闪烁。
- 广场：hero 光晕呼吸、外圈缓慢旋转、精选图卡上下浮动。
- 卡片：悬停上浮、图片缓速放大、边框和底部光的出现。
- 上传：投放区同心圆缓慢旋转，拖入时整块发光。
- 所有动效都受 `prefers-reduced-motion: reduce` 约束；开启后停止漂移、旋转和浮动，只保留状态色变化。
- 玻璃虚化只用在顶栏、侧栏、弹窗、预览层和少数信息卡上，不给每一张图片卡片都加 backdrop-filter，避免长列表在低端设备上掉帧。

## 5. 代码落点

| 文件 | 作用 |
|---|---|
| `web/src/styles/tokens.css` | 双主题变量、基础背景、字体、圆角、断点 |
| `web/src/styles/theme.css` | 组件覆盖、广场 hero、卡片、登录、预览、上传、相册、动效与响应式 |
| `web/src/core/theme.ts` | 主题读取/切换/记忆、系统偏好监听、背景萤火与环境层 |
| `web/src/ui/brand.ts` | 原创翼标、太阳/月亮图标、品牌锁定组合 |
| `web/src/ui/shell.ts` | 顶栏主入口、主题开关、侧栏、底栏、当前页高亮 |
| `web/src/pages/plaza.ts` | 广场 hero、随机一帧、换一批、紧凑上传入口 |
| `web/src/ui/widgets.ts` | 可见页面标题、图片卡片标题/浏览量 |
| `web/src/upload/panel.ts` | 广场紧凑上传形态与完整上传页的共用面板 |
| `web/src/pages/albums.ts` | 可见标题、移动端工具栏换行 |
| `web/src/pages/login.ts` / `register.ts` / `reset-password.ts` / `complete-signup.ts` | 统一认证卡片与品牌头 |
| `web/src/index.html` | 首绘前定主题、`color-scheme`、`theme-color` |
| `web/src/favicon.svg` / `manifest.webmanifest` | 翼标图标与深色启动底色 |

## 6. 资产边界

- 翼标、光轨、萤火、卡片光效都是本站原创的 CSS/SVG 表达，不使用《崩坏：星穹铁道》的官方立绘、Logo 或游戏截图。
- 如果后续要把流萤本人或萨姆的官方素材放进站点，需要先确认素材授权与使用范围；否则建议保持「取其气质、不取其形象」的处理。
- 广场 hero 的精选图直接取站点里的公开图片，不额外维护一套宣传图。

## 7. 验收记录

- `npm run typecheck` 通过。
- `npm run build` 通过，产物仍是单文件 `main.css`/`main.js`，前端继续由 Rust 二进制嵌入。
- 用真实构建产物和模拟接口在 1440 桌面、390 手机宽度下检查过：广场、相册、上传、登录、预览层均可渲染；没有横向溢出。
- 主题切换实测：无手动选择时跟随系统，切换后写入 `pixora-theme`，刷新仍保留；顶栏按钮标签随主题更新。
- 未改任何后端接口、数据库结构或上传队列状态机。
