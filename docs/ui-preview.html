参数类型必填说明

thumbfile可选客户端生成的缩略图，服务端直接存，不做缩放

tagsstring可选逗号分隔，如 风景,旅行
visibilitystring可选public 或 private，默认 private
original_namestring可选保留原始文件名，仅内部记录，不出现在直链里

全局约束

横向不出现滚动条任何断点下 body 都不该横向滚动，这是最基础的验收项
移动优先写样式基础样式面向窄屏，宽屏用 min-width 逐步增强
安全区留白底部 tab 与操作条加 env(safe-area-inset-bottom)
横屏可用手机横屏时底部 tab 转为左侧窄栏，避免挤压内容高度
触控与鼠标区分用 hover 媒体查询，触屏不依赖悬停才显示的操作
打印与导出条款页提供打印样式，去掉导航只留正文
